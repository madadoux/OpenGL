Minimal Navigation SDK Engine Architecture (EN / AR)

This is the smallest “engine-grade” architecture that still scales to a real SDK: clean public API, stateful navigation core, platform adapters, map wrapper, routing client, and distribution pipeline.

1) Public SDK API (Facade) the only layer clients touchDXStability

English

Goal: Provide a small, intuitive, stable surface that hides all complexity.

  • Expose objects like: NavigationController, Route, NavigationSession.
  • Thread-safe: internal engine runs off-main; callbacks delivered on main.
  • Backward compatibility: deprecate before breaking.
  • Idiomatic: Kotlin coroutines/Flow; Swift async/await + delegate callbacks.

العربية

الهدف: واجهة بسيطة وثابتة تخفي تعقيد المحرك بالكامل.

  • تعرض كائنات واضحة مثل: NavigationController و Route و NavigationSession.
  • آمنة مع الـ Threads: المحرك يعمل بالخلفية، والـ callbacks ترجع للـ main thread.
  • توافق خلفي: اعمل Deprecation قبل أي كسر في الـ API.
  • شكل API طبيعي لكل منصة: Kotlin (coroutines/Flow) وSwift (async/await + delegates).
2) Session & State Machine controls lifecycle and guarantees correctnessEngine

English

Why: Navigation is stateful. A state machine prevents “impossible states”.

  • States: Idle → RouteSet → Navigating → Paused → Arrived → Ended
  • Events: start(), stop(), newLocation(), offRoute(), rerouteDone()
  • Single source of truth: publish immutable state snapshots to clients.

العربية

ليه: الملاحة فيها حالات (stateful). الـ State Machine تمنع أخطاء من نوع “حالة مستحيلة”.

  • حالات مثال: Idle → RouteSet → Navigating → Paused → Arrived → Ended
  • أحداث: start(), stop(), newLocation(), offRoute(), rerouteDone()
  • مصدر واحد للحقيقة: تبعث State Snapshots ثابتة (immutable) للمستخدم.
3) Route Progress + Map Matching snap noisy GPS to route geometryGeometry

English

What it does: Convert raw GPS points into “where am I on the route?”

  • Find nearest polyline segment; compute perpendicular distance.
  • Use heading + speed to avoid snapping to the wrong parallel road.
  • Keep a “progress index” (segment + distance along route).

Learn more: Map matching video (good intuition): YouTube

العربية

وظيفته: يحول GPS الخام إلى “مكاني الحقيقي على خط المسار”.

  • يحدد أقرب جزء من الـ polyline ويحسب المسافة العمودية عليه.
  • يستخدم الاتجاه (heading) والسرعة لتجنب الالتقاط لطريق موازي غلط.
  • يحفظ التقدم: رقم المقطع + المسافة المقطوعة على المسار.

مصدر مفيد: فيديو Map Matching: YouTube

4) Off-route Detection + Rerouting robust decision logic, not “panic reroute”Reliability

English

  • Off-route signals: distance-from-route, heading mismatch, repeated deviation.
  • Use hysteresis / debounce: require N bad samples before reroute.
  • Reroute strategy: background request, keep guidance stable until new route is ready.

العربية

  • إشارات الخروج: مسافة كبيرة عن المسار + اتجاه مخالف + تكرار الانحراف.
  • استخدم Hysteresis/ Debounce: لازم N قراءات غلط قبل قرار إعادة المسار.
  • إعادة المسار: طلب بالخلفية، وخلي الإرشادات ثابتة لحد ما المسار الجديد يجهز.
5) Sensor Fusion (GPS + IMU) tunnels & weak signal handlingKalman

English

Why: GPS is noisy and can “jump”. IMU helps stabilize pose and short gaps.

  • Use a Kalman filter (or complementary filter) to combine sources.
  • Dead reckoning for short intervals: velocity + gyro heading.
  • Always re-anchor to map matching once GPS recovers.

Videos: MathWorks sensor fusion series

العربية

ليه: الـ GPS بيهتز وبيعمل jumps. الـ IMU يساعد يثبت الحركة ويتعامل مع انقطاع قصير.

  • استخدم Kalman Filter أو Complementary Filter لدمج المصادر.
  • Dead reckoning لفترة قصيرة: سرعة + اتجاه من الجايرو.
  • لما GPS يرجع، ارجع اربط النتيجة بالـ map matching.

فيديوهات: سلسلة Sensor Fusion (MathWorks)

6) ETA Engine smoothing + stable UXProduct

English

  • Base ETA: remaining_distance / expected_speed.
  • Smoothing: moving average to avoid ETA “jumping”.
  • If backend provides traffic: blend live ETA with client estimate.

العربية

  • ETA الأساسي: المسافة المتبقية / السرعة المتوقعة.
  • تنعيم (Smoothing): Moving average عشان الـ ETA مايقفزش.
  • لو السيرفر عنده ترافيك: امزج ETA السيرفر مع تقدير الجهاز.
7) Routing Client your custom routing APIsHTTP

English

  • Encapsulate HTTP: retries, timeouts, auth, caching.
  • Return strongly typed models (Route, Leg, Maneuver).
  • Support cancellation: user changes destination mid-request.

العربية

  • غلف الـ HTTP بالكامل: retries وtimeouts وauth وcaching.
  • نماذج Typed واضحة: Route / Leg / Maneuver.
  • دعم الإلغاء: المستخدم غيّر الوجهة أثناء الطلب.
8) Map Engine Wrapper rendering + camera + tiles + stylesMapLibre

English

  • Abstract map provider so you can swap engines later.
  • Responsibilities: camera, route line rendering, markers, tile cache, style loading.
  • Keep map rendering independent from routing logic.

العربية

  • اعمل abstraction للمحرك عشان تقدر تغيّره لاحقاً.
  • مسؤولياته: الكاميرا، رسم خط المسار، العلامات، كاش التايلز، الستايل.
  • خلي الرندر منفصل عن منطق التوجيه والـ rerouting.
